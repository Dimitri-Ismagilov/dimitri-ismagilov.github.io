Portfolio Hemsidan

Det här är min personliga portfolio hemsidan som jag har byggt i min eliminerings moment i Fronted 1. 
Den innehåller lite information om mig, mina kunskaper, mina projekt samt hur man kan nå mig.

Tekniker i projektet.

HTML: Strukturen i webbplatsens innehåll, samt användning av semantiska element.
CSS: Design av hemsidan som anpassar sig till en viss del skärmstorlek via media queries.
JavaScript: Validering av kontaktformuläret. Hämtning av väderdata via OpenWeatherMap API
OpenWeatherMap API: för att hämta aktuell temperatur och fuktighet i Stockholm.

Funktioner

Navigeringsmeny: Hjälper att navigera mellan sidans sektioner.
Projekt-Slideshow: En dynamisk slideshow som visar upp alla mina projekt visuellt 
Ladda ner CV: användare kan ladda ner min CV i PDF format.
Formulärvalidering: Säkerställer att användare fyller i rätt data i formuläret.
Väderinformation: Visar aktuell temperatur och fuktighet i Stockholm.

Hur fungerar den.

HTML: strukturen är uppbyggt med HTML-element som header, om mig, footer och så vidare.
CSS: Designen görs visuellt tilltalande. CSS grid och flexbox används för layout. 
media queries säkerställer att designen anpassar sig till olika skärmstorlekar.
JavaScript: validateForm() används för att säkerställa att e-post innehåller rätt format och att ämne och meddelande är ifylld.
getWheather() är en funktion för att hämta väderdata från OpenWeatherMap och uppdaterar dynamisk med aktuell väderinformation i Stockholm.
